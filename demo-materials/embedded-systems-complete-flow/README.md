# 嵌入式系统原理完整流程演示材料包

这套材料用于在工程认证智能体中演示一门课程的完整业务流程：

上传材料 -> AI 提取课程/实验/评分项 -> 审核支撑关系 -> 形成能力图谱 -> 图谱诊断 -> 教学改进 -> 认证支撑。

## 推荐上传顺序

1. `01_course_syllabus_embedded_systems.txt`
   - 上传分类选：课程大纲
   - 用途：建立课程、课程目标、毕业要求指标点对应关系。

2. `02_lab_guide_embedded_systems.txt`
   - 上传分类选：实验指导书
   - 用途：建立实验项目、实验任务、实验产出和支撑指标点。

3. `03_project_list_embedded_systems.csv`
   - 上传分类选：实验项目清单
   - 用途：补充实验编号、实验名称、对应课程目标和指标点。

4. `04_rubric_embedded_systems.csv`
   - 上传分类选：评分表
   - 用途：后续达成度评价和认证支撑使用，当前也可作为评分项证据。

5. `05_attainment_results_embedded_systems.csv`
   - 上传分类选：评价结果
   - 用途：演示达成度评价输入，当前版本可作为后续 M6/第4步材料。

6. `06_improvement_record_embedded_systems.txt`
   - 上传分类选：其他
   - 用途：演示图谱诊断后形成教学改进记录。

## 期望系统识别出的核心节点

- 课程：嵌入式系统原理
- 课程目标：CO1、CO2、CO3、CO4
- 实验项目：EXP-EC2-01 到 EXP-EC2-04
- 评分项：R1 到 R5
- 目标指标点：C-01-01、C-02-01、C-03-01、C-05-01、C-08-01

## 期望审核通过的核心关系

- 嵌入式系统原理 -> C-01-01、C-02-01、C-03-01、C-05-01、C-08-01
- GPIO 与定时器综合实验 -> C-01-01
- 串口通信与协议解析实验 -> C-02-01
- 传感器数据采集与滤波实验 -> C-03-01、C-05-01
- RTOS 多任务调度实验 -> C-02-01、C-03-01

## 什么算演示完成

- 待审候选关系处理到 0 或只剩明确不采纳项。
- 能力图谱里能看到课程、实验、指标点之间的已确认关系。
- 图谱诊断能说明覆盖情况和缺口。
- 教学改进中能基于诊断问题创建或展示改进措施。
- 认证支撑页能基于已确认图谱生成说明。
