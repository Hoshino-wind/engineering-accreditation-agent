# 机械设计制造及其自动化专业演示材料

用途：用于演示多专业隔离和专业全局视角。该材料包与默认的电子信息/嵌入式示例不同，面向机械设计制造及其自动化专业，重点覆盖机械设计、数控加工、CAD/CAE、测量与误差分析等实验教学场景。

建议演示顺序：

1. 在左侧“认证专业”中添加或切换到“机械设计制造及其自动化”。
2. 上传 `01_mechanical_manufacturing_lab_guide.txt`，材料分类选择“实验指导书”，课程可填“机械制造工艺基础”。
3. 等待材料处理完成后进入图谱页，观察新专业下生成的课程/实验节点。
4. 切回原专业，确认两个专业的材料、图谱和诊断互不串数据。

说明：文件为脱敏示例材料，不包含学生个人信息。演示时可强调“专业是认证评判单元，不同专业拥有独立材料和图谱快照”。
