# 示例：一门课的完整填充

《传感器与检测技术》（实验），课程编号 EXP-2031。**课程、学生和分数全部虚构**，用于演示四份教学文档如何填满一份可验收的金标准。

## 文件

| 文件 | 是什么 | 谁填 |
| --- | --- | --- |
| [01-课程大纲.md](01-课程大纲.md) | 课程目标、目标↔指标点矩阵、实验一览 | 课程负责人，一次性 |
| [02-实验指导书.md](02-实验指导书.md) | 实验项目、对应课程目标、考核要求 | 任课教师，一次性 |
| [03-评分标准表.md](03-评分标准表.md) | 评分项、满分、对应课程目标、权重 | 任课教师，一次性 |
| [04-成绩记录表.csv](04-成绩记录表.csv) | 逐生逐项原始分（宽表） | 任课教师，**每学期一份** |
| `sample.json` | 上面三份文档的机读形式 + 人工结论 | 由 01–03 抄录 |
| `scores.csv` | 04 转换而来的长表 | `make convert-scores` 生成 |

前三份是一次性建设，之后每学期只需重填文档 4。

## 这个示例刻意演示的四件事

### 1. 评分项跨实验聚合到课程目标

CO-1 的三个评分项分散在实验一和实验三：

```
RC-0101（实验一）权重 0.30 ┐
RC-0301（实验三）权重 0.45 ├─→ CO-1 → PI-4.2
RC-0302（实验三）权重 0.25 ┘   合计 1.000
```

所以**权重必须挂在「评分项 → 课程目标」关系上，不能挂在实验上**，也不能用大纲表E 的考核环节权重代替。这两套权重是不同的东西，混用是达成度算错的常见原因。

### 2. 缺考按声明口径处理，不是随手补零

S04 缺席实验二。当前口径 `missing_score: exclude`，所以 RC-0201 与 RC-0202 的分母从 12 减为 11：

- exclude：172 ÷ 11 ÷ 20 = 0.782
- 若改成 zero：172 ÷ 12 ÷ 20 = 0.717

**同一批数据差 0.065。** 这就是口径必须先冻结的原因。

### 3. 阻断是常态，不是异常

CO-3 是 2024 版大纲新增的课程目标，v1.0 评分表还没设立对应评分项列，因此本学期没有任何数据。

系统必须报**输入阻断**，达成度和结论都为空。它不等于"未达成 0.00"——前者是"数据没采集"，后者是"学生没达标"，处置方式完全不同：前者要评分表升版增列，后者要教学改进。

这正对应真实资料盘点的情况：9 门课只有 3 份评分表。

### 4. 每个数字都能回到原文

样例里 21 个节点、37 条关系，每一条都带完整 sha256 摘要和页码定位，例如：

```
CO-2 -SUPPORTS-> PI-4.3
  来源：《传感器与检测技术》实验教学大纲 v1.2
  定位：第 2 页 / 表C 课程目标与指标点对应矩阵
```

## 从真实课程复制这套结构

```bash
mkdir -p .local-data/golden-sample/<课程代号>
cp golden-sample/templates/sample.template.json .local-data/golden-sample/<课程代号>/sample.json

# 教师用 Excel 填宽表后导出 CSV，再转换（自动脱敏学号）
make convert-scores SRC=<宽表.csv> OUT=.local-data/golden-sample/<课程代号>/scores.csv

make verify-golden DIR=.local-data/golden-sample/<课程代号>
```

宽表的列名以评分项编号开头即可，例如 `RC-0101(满分15)`。缺考留空或填「缺考」「缺席」「-」都能识别。

> `.local-data/` 已被 `.gitignore` 排除。真实成绩不得进仓库。
