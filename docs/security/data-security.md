# 数据安全与合规基线

## 1. 保护对象

系统可能处理：

- 学生姓名、学号、班级和成绩。
- 实验报告、代码、截图和教师评语。
- 培养方案、课程大纲、评分规则和认证过程材料。
- 用户身份、角色、操作日志和模型调用记录。

这些数据默认按校内受控数据处理。是否允许调用校外模型、保留多长时间、谁可导出，应由学校制度和项目数据分级共同决定。

## 2. 基本原则

- **最小化**：仅收集业务必需字段。
- **目的限制**：上传用于认证分析的数据不得自动用于其他模型训练。
- **最小权限**：用户、服务和任务只获得完成职责所需权限。
- **默认拒绝**：未明确授权的材料、专业和教学班不可见。
- **全程可审计**：关键查看、下载、审批、导出和模型调用可追踪。
- **分层防护**：浏览器、API、数据库、对象存储、Worker 和模型分别设防。

## 3. 身份与权限

### 3.1 登录

- 使用 OIDC Authorization Code 流程。
- 后端会话优先，Cookie 设置 `HttpOnly`、`Secure` 和适当的 `SameSite`。
- 会话具备空闲超时、绝对有效期和主动注销。
- 生产环境不提供共享管理员账号。

### 3.2 授权

同时使用角色和数据范围：

- 角色决定能否上传、审核、评价、导出和管理。
- 数据范围限制到学校、学院、专业、课程、教学班或学期。
- API 每次读取和写入都在服务端校验，前端隐藏按钮不构成安全控制。
- 对成绩明细、学生报告、批量下载和模型外发设置更高权限。

### 3.3 服务身份

API、Worker、迁移任务和备份任务使用不同凭据。数据库、对象存储和模型密钥只存在于服务端密钥管理中，不进入前端包、镜像层或 Git。

## 4. 文件安全

- 使用服务端签发的短时预签名地址，不公开对象存储桶。
- 上传后校验扩展名、MIME、文件头、大小和内容哈希。
- 在解析前进行恶意文件扫描；宏和可执行内容不得直接运行。
- 对象键不包含姓名、学号等个人信息。
- 原始文件、解析产物、脱敏片段和导出包使用不同前缀与权限策略。
- 下载和批量导出记录操作者、范围、时间和用途。
- 临时文件在任务结束后按策略清理。

## 5. 个人信息与向量数据

- 姓名、学号等标识字段单独受控，不嵌入向量。
- 生成向量前对正文执行个人信息检测和令牌化。
- 向量表保存租户、专业、课程、材料版本和权限标签。
- 检索必须先进行结构化权限过滤，再进行相似度排序。
- 删除原始材料时，同步删除派生文本、向量、缓存和导出副本。
- 用不可逆哈希做关联时应加入系统管理的盐，避免枚举还原。

## 6. 模型调用安全

### 6.1 模型分级

为模型部署配置数据能力标签：

- `public-only`：仅允许公开或完全脱敏内容。
- `internal`：允许校内非个人敏感教学材料。
- `restricted`：在校内部署并获授权后，才能处理受限数据。

请求进入适配层时，根据数据级别和用途选择允许的模型；不满足要求时拒绝或先脱敏。

### 6.2 防止提示注入与越权

- 将文件正文视为数据，不执行其中的指令。
- 工具调用采用白名单和结构化参数。
- 检索结果只来自当前用户有权访问的范围。
- 模型不能直接写入正式关系、成绩、评价结果或权限数据。
- 批量关系建议必须经过差异预览和人工确认。

### 6.3 数据保留

与外部模型供应方明确：

- 输入输出是否用于训练。
- 日志保存位置和期限。
- 删除和审计能力。
- 传输和存储区域。

无法满足学校要求时，应改用校内部署模型或关闭相应功能。

## 7. 数据库与审计

- 生产数据库启用传输加密，备份同样加密。
- 正式评价运行和审批记录采用追加或不可变快照，禁止静默覆盖。
- 审计事件包含操作者、动作、资源、范围、结果、请求 ID、时间和来源。
- 审计日志不得记录访问令牌、密码、对象存储密钥或完整学生正文。
- 对高风险操作设置告警，例如跨课程批量下载、角色提升和大量导出。

## 8. 生命周期与恢复

- 为原始材料、处理产物、模型日志、审计记录和评价快照分别定义保留期。
- 支持课程或教学班按授权归档和删除。
- 定期执行数据库和对象存储备份。
- 恢复演练必须验证数据库记录、对象版本和引用关系的一致性。
- 发生泄露或误授权时，能够根据审计记录确定影响范围并撤销会话、密钥和预签名链接。

## 9. 上线安全门槛

- 完成数据分级与模型使用审批。
- OIDC、角色和数据范围测试通过。
- 未授权课程、文件和向量检索均返回拒绝。
- 仓库和镜像完成密钥扫描。
- 文件上传、恶意文件、越权下载和提示注入测试通过。
- 备份恢复演练通过。
- 关键操作和模型调用具备可查询审计记录。
