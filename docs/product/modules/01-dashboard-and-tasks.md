# M1 总览与任务工作台

## 1. 模块定位

本模块是用户进入系统后的工作入口，汇总当前专业、评价周期、图谱建设进度、异步任务和人工待办。

它不复制业务对象，也不允许在总览中绕过所属模块完成正式审核。

## 2. 用户结果

- 用户知道当前正在处理哪个专业和周期。
- 教师能看到材料、候选关系、评价和改进待办。
- 负责人能识别阻断图谱建设或评价的关键问题。
- 失败任务有明确原因、下一步和目标页面。

## 3. 参与角色

- 实验教师：查看课程相关待办。
- 课程负责人：查看审核、评价和逾期事项。
- 专业负责人：查看跨课程建设进度和阻断项。
- 系统管理员：查看处理任务和基础设施异常。

## 4. 核心对象

| 对象 | 说明 |
| --- | --- |
| `AccreditationWorkspace` | 当前专业和认证工作的业务容器 |
| `EvaluationCycle` | 当前评价周期 |
| `ReadinessSnapshot` | 各模块状态聚合结果 |
| `WorkItemIndex` | 指向业务模块待处理对象的索引 |
| `ProcessingJob` | 异步任务权威状态 |
| `JobAttempt` | 单次执行、处理器版本和错误 |

## 5. 主流程

1. 用户进入有权限的工作空间。
2. 系统汇总图谱、材料、审核、评价和改进状态。
3. 用户按角色查看“我的待办”和失败任务。
4. 点击待办跳转到事实所属模块。
5. 业务动作完成后，工作台根据事件自动更新。
6. 可重试任务按幂等策略重新执行。

## 6. 状态与规则

任务状态：

```text
queued → running → succeeded
            ↘ retry_scheduled → running
            ↘ failed / canceled
```

工作项状态：

```text
open → in_progress → completed / no_longer_applicable
```

- 总体进度由真实模块状态聚合，不允许手工设置完成率。
- 工作项不能在总览强制完成，只能由所属模块事件关闭。
- 重试不得重复创建材料、关系、评价或导出产物。
- 用户只能看到其角色和数据范围内的任务。

## 7. 输入与输出

输入：

- M2～M8 的对象状态、工作项和业务事件；
- M9 的用户、角色和数据范围。

输出：

- 当前上下文；
- 我的待办、失败任务和下一步；
- 模块建设进度和阻断项；
- 跳转到目标业务对象的稳定链接。

## 8. 页面范围

- 专业与周期选择。
- 图谱建设进度。
- 我的待办和即将到期。
- 处理任务、失败原因和重试入口。
- 评价、诊断和改进摘要。

## 9. 非目标

- 不建设通用项目管理、BPM 或工单平台。
- 不在总览展示大而空的装饰性指标。
- 不复制业务审核表单。
- 不直接暴露 Celery 或 Redis 内部术语。

## 10. 验收标准

- 用户只能进入其有权限的工作空间。
- 各类待办能跳转到正确模块和对象。
- 业务动作完成后待办自动关闭。
- 任务失败展示标准错误类别和下一步。
- 幂等重试不产生重复正式数据。
