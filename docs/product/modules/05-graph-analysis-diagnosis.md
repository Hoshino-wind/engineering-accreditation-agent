# M5 图谱分析与一致性诊断

## 1. 模块定位

本模块基于正式能力图谱和受控材料执行覆盖分析、一致性检查、结构诊断和版本影响分析，形成可追溯的问题发现。

确定性关系检查由规则和图算法完成；复杂文本语义判断可以使用 AI，但诊断结论必须展示依据并由用户确认。

## 2. 用户结果

- 专业负责人能识别能力、课程、实验、评分和证据之间的断点。
- 教师能发现大纲、指导书和评分表之间的逻辑冲突。
- 上游对象变化时能看到受影响关系、评价和报告。
- 诊断发现可以直接转为材料补充、关系修正或持续改进问题。

## 3. 参与角色

- 课程负责人：处理课程材料和关系一致性问题。
- 专业负责人：查看跨课程覆盖和能力分布。
- 认证工作组：检查证据完整性和认证支撑风险。
- AI 辅助能力：解释复杂语义冲突，不直接修改图谱。

## 4. 核心对象

| 对象 | 说明 |
| --- | --- |
| `AnalysisRuleVersion` | 覆盖、一致性和结构规则版本 |
| `GraphAnalysisRun` | 固定图谱版本的一次分析 |
| `DiagnosticFinding` | 缺口、冲突、重复、集中或失效发现 |
| `FindingEvidenceRef` | 支撑发现的节点、关系和材料来源 |
| `ImpactAnalysis` | 版本变化的下游影响 |
| `FindingDecision` | 确认、忽略、豁免或转问题的决定 |

## 5. 分析能力

### 覆盖分析

- 指标点是否有课程目标支撑；
- 课程目标是否有实验支撑；
- 实验是否有评分项；
- 能力是否有教学资源和有效证据。

### 一致性检查

- 大纲、指导书、评分表中的实验名称和目标是否一致；
- 评分项是否实际评价声明的能力；
- 分值、权重和等级描述是否一致；
- 同一实验跨材料描述是否冲突。

### 结构诊断

- 能力没有实验培养；
- 实验重复支撑过多目标；
- 知识点存在断层；
- 支撑关系过度集中；
- 教学资源与实验要求不匹配。

### 影响分析

- 图谱节点或关系变更影响哪些评价、改进事项和支撑包。

## 6. 状态与规则

```text
queued → running → completed
                     → finding_open
                     → confirmed / exempted / dismissed
                     → converted_to_action
```

- 分析运行固定图谱、材料和规则版本。
- 确定性规则结果与 AI 语义判断明确区分。
- AI 判断必须引用当前授权范围内的材料。
- 诊断发现不能直接修改正式图谱或关闭改进问题。
- 豁免必须记录范围、原因、批准人和有效期。

## 7. 输入与输出

输入：

- M2 的正式图谱版本；
- M3 的材料与证据；
- M6 的评价异常；
- M9 的数据范围和模型政策。

输出：

- 覆盖矩阵和能力分布；
- 材料一致性报告；
- 结构问题和版本影响清单；
- 发送到 M3/M4 的修正入口；
- 发送到 M7 的已确认问题。

## 8. 页面范围

- 图谱健康概览。
- 覆盖矩阵和缺口列表。
- 材料一致性检查。
- 结构诊断和来源侧栏。
- 版本影响分析。
- 确认、豁免、忽略和转改进操作。

## 9. 非目标

- 不把可视化图表当作诊断事实。
- 不自动修复正式图谱。
- 不用 AI 替代确定性覆盖检查。
- 不建设无限扩展的通用图分析平台。

## 10. 验收标准

- 能识别未覆盖课程目标、无评分项实验和无证据能力。
- 能发现至少一类跨材料不一致问题并定位原文。
- 分析结果可追溯到图谱、规则和材料版本。
- 确认问题可以转入 M7，修正项可返回 M3/M4。
- 图谱变更能够列出受影响评价和支撑包。

## 11. 当前实现阶段

当前 PC 端原型已覆盖：

- 课程、发现类型、风险和关键词组合筛选；
- 覆盖缺口、材料冲突、结构风险和版本影响四类诊断发现；
- 来源对象、缺失或冲突关系、目标对象的结构化对照；
- 确定性规则与语义辅助判断的显式区分；
- 规则编号、规则集版本、图谱版本、材料快照和分析时间追溯；
- 课程目标、能力节点和评价输入的影响范围查看；
- 覆盖路径断点可视化，以及材料坐标、原文片段和哈希依据核验；
- 确认问题、转入改进、返回 M4、豁免和忽略五类本地处置草稿；
- 从 M1 进入 M5，以及从 M5 返回 M4 的页面级闭环入口。

当前页面数据使用显式标记的 `prototypeOnly` 试点示例。诊断运行、正式处置写入、豁免审批、创建 M7 改进问题和版本影响计算尚未接入后端，相关提交按钮保持禁用，处置草稿刷新后不保留。
